# ml-classification-metrics-analysis
End-to-end binary classification project demonstrating model evaluation techniques including Precision, Recall, F1-score, ROC Curve, AUC, and class imbalance handling.

# Project Overview

This project demonstrates the implementation and evaluation of classification models using machine learning techniques. The focus is on understanding model performance metrics and handling imbalanced datasets.

The project is implemented using Python and the scikit-learn library.

# Objectives

Implement Logistic Regression for binary classification

Evaluate model performance using multiple metrics

Understand Confusion Matrix interpretation

Plot ROC Curve and compute AUC score

Handle imbalanced data using class weights

Compare performance with Decision Tree Classifier

# Models Implemented

Logistic Regression

Logistic Regression (with class_weight='balanced')

Decision Tree Classifier

# Dataset

The project uses the Breast Cancer dataset available in scikit-learn.

# Key Learnings

Accuracy is not always reliable for imbalanced datasets

Precision–Recall tradeoff is critical in classification problems

ROC-AUC provides better insight into model performance

Class weights help improve performance on minority classes
